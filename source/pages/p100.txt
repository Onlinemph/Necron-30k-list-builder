               Power of the C’Tan

      Each model with the C'Tan Unit Type gains a Power of the C'Tan during the controlling player's
       Shooting Phase as the Active Player. When a model that can use the Powers of the C'Tan is selected to
      make a Shooting Attack during the Controlling Player's Shooting Phase, first roll a D6 and consult the
       following list of Powers of the C’Tan. This model may make a Shooting Attack using the weapon profile
       corresponding to the number rolled, in addition to any other Ranged Weapons it has. If a model using a
      Power of the C’Tan is a Vehicle, the Attack is made as if the Power of the C'tan was a Turret-mounted
      weapon.
